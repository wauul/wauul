## 👋 About me

AI-driven developer with an MSc in Software, Web & Mobile Development (Epitech MSc Pro, Promo 2024), based in Marseille, France. I build end-to-end web & mobile products with real AI features, from API design to the last pixel of the UI. I like shipping fast without breaking things — clean architecture, boring reliability, no over-engineering.

**Focus areas**

- 🎨 **Frontend** — React & Next.js interfaces, Tailwind, Capacitor mobile apps
- ⚙️ **Backend / APIs** — TypeScript services, webhooks, queues, Postgres
- 🤖 **AI integration** — RAG and LLM features wired into real products
- ☁️ **DevOps / deployment** — Docker, GitHub Actions, Vercel

## 🚀 Featured projects

Six things I've built — most of them live:

Capacitor mobile app with push notifications. `TypeScript`
- **[hooka-relay](https://github.com/wauul/hooka-relay)** · [![Live](https://img.shields.io/badge/Live-Demo-2ea44f?style=flat-square)](https://hooka-relay.com) — Reliable webhook delivery service (Svix/Hookdeck-style): automatic retries, exponential backoff, per-endpoint circuit breaking, HMAC-signed idempotent deliveries. `TypeScript`
